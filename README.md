# ЧИПОК

Telegram Mini App marketplace.

## MVP
- Telegram Mini App auth
- Catalog, categories and products
- Seller stores
- Cart and orders
- Seller/buyer chat and offers
- Payments with server verification
- Marketplace commission
- Seller ledger/balance
- Moderation and admin foundation

## Rules
- No geolocation
- No delivery in v1
- Fulfillment: meeting or pickup
- No subscriptions or seller plans

## CI
GitHub Actions runs typecheck and build on pushes to main and pull requests.
