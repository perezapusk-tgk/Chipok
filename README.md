# Nookly

Telegram Mini App marketplace.

## MVP
- Telegram Mini App authentication
- Catalog, categories and products
- Seller stores and unlimited seller onboarding
- Cart and multi-seller orders
- Seller/buyer chat and offers
- Direct buyer-to-seller payment instructions (SBP, card details or payment link)
- Seller confirms receipt only after checking their bank/payment provider
- Six-digit handover code after seller marks an order ready
- Notifications, disputes, moderation and admin foundation

## Product rules
- No subscriptions or seller plans
- No seller-count ceiling
- No marketplace sales commission in the direct-settlement model
- No geolocation collection
- No delivery service in v1; pickup or meeting is agreed in chat
- Product prices are RUB in v1
- The seller is responsible for lawful goods, payment details, fulfillment and legally required refunds

## CI
GitHub Actions runs typecheck and build on pushes to main and pull requests.
