# ЧИПОК — платежи

## Как работает оплата

1. Покупатель оформляет заказ в Mini App.
2. API повторно проверяет цену и резерв товара.
3. API создаёт Telegram invoice link через Bot API.
4. Mini App открывает invoice через `Telegram.WebApp.openInvoice()`.
5. Telegram показывает встроенную форму оплаты.
6. Для физических товаров используется подключённый в BotFather платёжный провайдер; Telegram сам деньги не принимает и комиссию за Payments API не удерживает.
7. Bot webhook получает `pre_checkout_query`, проверяет заказ/сумму и отвечает Telegram.
8. После `successful_payment` API идемпотентно переводит заказ в `paid`, фиксирует платёж и записывает продавцу его сумму и комиссию платформы в ledger.

## Важное про деньги

Комиссия ЧИПОК не хранится «в Telegram». Telegram является интерфейсом платежа, а фактический денежный расчёт выполняет выбранный платёжный провайдер. Поэтому:

- покупатель платит внутри Telegram;
- деньги поступают на подключённый merchant/payment-provider аккаунт;
- в ЧИПОК фиксируется, например, продажа 5 000 ₽, комиссия 5% = 250 ₽, продавцу = 4 750 ₽;
- деньги продавца и комиссия учитываются раздельно в ledger;
- вывод комиссии владельцу и выплаты продавцам делаются через выбранную платёжную схему.

Количество продавцов не ограничивается техническим лимитом. Marketplace может масштабироваться по мере необходимости; payout-слой подключается отдельно и не меняет покупательский UX.

## Переменные

`TELEGRAM_BOT_TOKEN` — токен бота.

`TELEGRAM_PROVIDER_TOKEN` — токен физического платёжного провайдера, подключённого через BotFather → Payments.

`TELEGRAM_PAYMENT_CURRENCY=RUB` — валюта заказа.

`TELEGRAM_PAYMENT_WEBHOOK_SECRET` — секрет для webhook.

`PLATFORM_COMMISSION_BPS=500` — комиссия 5%.

Telegram официально поддерживает встроенные invoice/payment формы в Mini Apps и метод `openInvoice`; для физических товаров используется сторонний payment provider, а не Telegram Stars.
